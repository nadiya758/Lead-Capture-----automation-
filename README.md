Lead Capture Automation using n8n

Project Overview

This project automates lead collection, email validation, lead storage, personalized welcome emails, and team notifications using n8n.

Workflow

1. Collect Name, Email, and Learning Interest through an n8n form.
2. Validate the submitted email address using an IF node.
3. Store valid leads in Airtable.
4. Generate a personalized welcome email using AI.
5. Send the welcome email through Gmail.
6. Notify the team through Slack.
7. Route invalid email submissions separately.

Tools and Technologies

- n8n
- Airtable
- OpenAI API
- Gmail
- Slack
- Email validation with Regex

Key Features

- Automated lead collection
- Email format validation
- Separate valid and invalid lead handling
- AI-generated personalized welcome emails
- Automated notifications
